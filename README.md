# Ahmedpura News Group

A responsive Hindi landing page for Ahmedpura News Group.

## Files
- `index.html` — complete website (HTML, CSS and JavaScript in one file).

## Publish with GitHub Pages
1. Open the repository Settings.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish the site.

## Before publishing
Replace the placeholder email, phone/WhatsApp number and social links in the contact section. The news cards currently contain clearly marked demo text; replace them with verified news before sharing the site.
